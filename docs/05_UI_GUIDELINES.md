# UI Guidelines

## 성격

EvalFlow는 홍보 사이트가 아니라 학교 업무용 애플리케이션이다.

## 기본

- 시스템 기본 글꼴
- 본문 14~16px 수준
- 페이지 제목도 과도하게 크게 만들지 않음
- 흰색/중립 배경
- 단일 강조색
- 오류/주의/완료 상태에 필요한 색만 사용

## 금지

- 이모지
- 장식성 아이콘 남발
- 그라데이션
- 네온
- Glassmorphism
- 불필요한 애니메이션
- 거대한 Hero 영역
- "혁신적인 AI 평가 플랫폼" 같은 홍보 문구
- 모든 정보를 카드로 쪼개는 대시보드

## 관리자 화면

표, 검색, 필터, 상태가 핵심이다.

예:

```text
교과 | 학년 | 담당자 | 상태 | 검증 | 수정일
```

## 교사 화면

로그인 후 바로 본인이 해야 할 업무를 보여준다.

```text
2027학년도 1학기
3학년 영어
상태: 작성 중
[계속 작성]
```

## 접근성/사용성

- 아이콘만 있는 버튼보다 텍스트 버튼 우선
- 오류는 색만으로 표현하지 않고 텍스트 제공
- 폼 라벨을 생략하지 않음
- 표의 열 이름을 명확하게 사용
