# Product Scope

## 제품 한 문장

교사가 교과 평가 정보를 한 번 입력하면 시스템이 구조적 오류를 검증하고, 평가관리자가 취합하여 정형화된 결과물을 생성할 수 있게 하는 웹 기반 업무 시스템.

## 대회용 MVP 핵심 범위

1. 평가계획 작성
2. 자동 검증
3. 제출
4. 평가관리자 취합/검토
5. 최종 출력

## 사용자 역할

### SCHOOL_ADMIN
학교 시스템 관리자.

- 학교 사용자 계정 발급/비활성화
- 역할 부여
- 평가관리자 지정
- 학교 기본 설정

평가업무 내용 전체를 관리하는 역할과 계정/권한 관리 역할을 분리한다.

### EVALUATION_ADMIN
부장, 평가계 등 평가업무 관리자.

- 평가계획 작성 현황 확인
- 제출 계획 검토/반려/승인
- 학사일정 및 평가 공통 설정
- 전 교과 자료 출력

### TEACHER
일반 교사.

- 본인에게 배정된 학년/교과 평가계획 작성
- 검증
- 제출
- 반려된 계획 수정

## 개인정보/표시 원칙

시제품은 공개 웹에서 실행하는 것을 가정한다.
교사 표시명은 기본적으로 `김OO (영어)` 형태를 사용한다.
내부 식별자는 UUID/Auth UID 등 별도 고유 ID를 사용한다.

공개용 문서 생성 시 교사명은 기본적으로 제외할 수 있도록 출력 정책을 분리한다.

## 제품 원칙

- 동일 정보는 한 번만 입력한다.
- 교사는 HWP 서식을 직접 맞추지 않는다.
- 학교별 문서 모양은 Template 계층에서 처리한다.
- 정기고사 일정 등 학교 공통정보는 중앙 설정을 참조한다.
- 일반 교사 화면은 작성에 필요한 기능만 보여준다.

## MVP 밖이지만 확장 가능해야 하는 기능

- 학교별 Template 생성/관리
- AI 내용 검토
- 전교과 평가요약표
- 교육계획서용 출력
- 학부모 공개용 출력
- NEIS Export Adapter
- 수행평가 일정 집중도 분석
