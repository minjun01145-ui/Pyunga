# AI Review module

AI가 문서의 의미를 해석하거나 구조화해야 하는 기능에서 사용하는 공통 AI 경계입니다.

허용 예:
- 전년도 문구
- 타 교과 문구
- 모호한 세부평가기준
- 성취기준과 평가내용의 의미적 연결 검토 제안
- 업로드한 학교 문서에서 검토 대상 정보를 구조화하여 제안

금지:
- 반영비율 계산
- 역할 판정
- AI 응답을 검증 없이 공식 데이터로 확정

Application 계층은 `AiJsonClient` 인터페이스에만 의존합니다. Ollama 같은 공급자별 HTTP 구현은 infrastructure에 둡니다.
AI 응답은 업무 모듈의 Zod schema와 업무 규칙으로 검증한 뒤, 사용자가 확인할 수 있는 제안 데이터로 사용합니다.
